# Portafolio Frontend - Fiorela Mamani

Portafolio personal desarrollado para mostrar mis habilidades como Desarrolladora Frontend Semisenior.

## 🛠️ Tecnologías
- Angular 19 (Standalone Components)
- Tailwind CSS v4
- Lucide Icons

## 🚀 Ejecución local
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Levantar el servidor: `ng serve`
4. Abrir en el navegador: `http://localhost:4200`
